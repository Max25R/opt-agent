opt-agent

A plain-English operations problem goes in. Claude writes it as a linear or integer program, CBC solves it, HiGHS and plain arithmetic check the answer independently, and Claude explains it using only the solver's numbers. Nothing unverified is presented as an answer.

connecting…

This is the demo as a static page: no server, no API key, and nothing you type is sent anywhere. When the page was built, the demo app replayed each example's committed Claude replies, solved Claude's models with CBC and HiGHS, ran the arithmetic checks, and saved what it returned; this page shows those saved responses. To solve a problem of your own, run the demo with your own Anthropic key (how).
